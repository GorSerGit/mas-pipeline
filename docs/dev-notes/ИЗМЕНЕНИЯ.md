# Изменения относительно mas-pipeline-mobile-integrated1

| Файл | Что изменено |
|---|---|
| services/tester/main.py | WEB проверяется вместе с бэкендом, принятым в этом же прогоне (ждёт его до WEB_BACKEND_WAIT, по умолчанию 3600 с; отдельная docker-сеть, бэкенд доступен вебу как backend:8080). Тесты WEB с живым бэкендом могут проверять полный сценарий (заполнить — нажать — увидеть). Без бэкенда 502/504 не выдаются за «вероятную причину». Ошибка подъёма бэкенда для проверки — status error (инфраструктура), а не провал веба. Логика MOBILE/no_kvm не тронута. |
| services/web/developer.py | Правила: кнопка формы блокируется только `form.invalid \|\| saving`; у каждого `.subscribe` есть `error`, сбрасывающий loading/saving; страница работает при ошибке бэкенда; после создания — сброс формы и обновление списка. Проверки кода: `[disabled]` с `loading` и `.subscribe` без `error` не принимаются. |
| services/backend/devops.py | Пакет prometheus-net.AspNetCore в Backend.csproj. |
| services/backend/developer.py | Program.cs: `using Prometheus;`, `app.UseHttpMetrics();`, `app.MapMetrics().ExcludeFromDescription();` (эндпоинт /metrics, в OpenAPI не попадает); проверка, что MapMetrics есть. |
| services/orchestrator/main.py | Продукт: полный GitLab CI/CD (build → test → package → deploy; staging автоматически, production вручную; smoke-тест /health и /metrics), monitoring/prometheus.yml и alerts.yml, сервис prometheus в docker-compose (профиль monitoring), PROMETHEUS_PORT в .env.example. В агент документации передаются фактические файлы эксплуатации. |
| services/docs/main.py | Новый документ operations.md: CI/CD, стенды, переменные, порты, /health, мониторинг Prometheus — строго по переданным файлам. |
| ui/src/app/pages/generator/generator.scss | Заменён на присланный вариант. |
| ui/src/app/pages/generator/generator.html | Классы приведены к новому generator.scss (generator-grid, panel-card, panel-header/body, code-input, metrics-bar, submit-btn, terminal-wrapper/header/body, log-line, file-explorer). Логика не менялась. |
| .gitignore (новый) | .env, __pycache__, node_modules. |
